# 15.561 FA26 HW 3: AI-Assisted Business Data Analysis

Analysis of the Northwind database, built with the help of Claude Code.
The results are presented on a webpage with at least three business
questions, each with its analysis, visualization, main finding, and
business implication.

- **Webpage:** `docs/index.html` (published via GitHub Pages)
- **Analysis code:** `analysis/` (Python only)
- **Figures:** `docs/figures/` (generated by the analysis scripts)

## How to reproduce

1. Clone this repository and enter it:

   ```bash
   git clone https://github.com/hangzhao1006/hangz-15561-hw2.git
   cd hangz-15561-hw2
   ```

2. Create the environment and install dependencies:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

3. Place the Northwind SQLite database at `data/northwind.db`
   (see `data/README.md`).

4. Run the analysis scripts from the `analysis/` directory; each one
   writes its figures to `docs/figures/` and prints summary statistics:

   ```bash
   cd analysis
   python q1_market_trends.py        # market growth/decline by country
   python q2_product_concentration.py # product revenue concentration
   python q3_fulfillment.py          # late-shipment analysis
   ```

5. Open `docs/index.html` in a browser to view the webpage locally.
   The published version is served by GitHub Pages from `docs/`.
